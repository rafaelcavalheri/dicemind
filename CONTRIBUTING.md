# Como Contribuir

Obrigado pelo interesse em contribuir com o DiceMind!

## O que pode ser contribuído

Este repositório contém a documentação e configurações públicas do jogo. Contribuições bem-vindas incluem:

- Correções na documentação (`README.md`, `master.md`)
- Traduções para outros idiomas
- Sugestões de regras e mecânicas via Issues
- Relatórios de bugs via Issues

## Fluxo de trabalho

1. Faça um fork do repositório.
2. Crie uma branch descritiva: `git checkout -b melhoria/descricao-curta`
3. Faça as alterações e commit com mensagem clara:
   ```
   docs: corrige instrução de instalação no README
   fix: remove referência quebrada ao arquivo de regras
   feat: adiciona configuração de idioma ao master.md
   ```
4. Abra um Pull Request descrevendo o que foi alterado e por quê.

## Convenção de commits

Use o padrão [Conventional Commits](https://www.conventionalcommits.org/pt-br/):

| Prefixo | Uso |
|---|---|
| `feat` | Nova funcionalidade ou configuração |
| `fix` | Correção de erro |
| `docs` | Alteração somente em documentação |
| `refactor` | Reorganização sem mudança de comportamento |
| `chore` | Tarefas de manutenção (CI, dependências) |

## Reportando bugs

Abra uma [Issue](https://github.com/rafaelcavalheri/dicemind/issues) com:

- Descrição clara do problema
- Passos para reproduzir
- Comportamento esperado vs. observado
- Versão do app e sistema operacional
